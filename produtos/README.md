# produtos/

Cada produto da Faixa Preta tem uma pasta aqui, criada pelo departamento de Produto (`agents/produto/`).

## Estrutura de um produto
```
produtos/<nome>/
  01-selecao.md
  02-segredo.md
  modelo/            código-fonte e .stl numerados (v1, v2...)
  03-validacao.md
  final/             .stl aprovado + ficha-producao.md
```

## Regras
- Conteúdo interno. Nada daqui vai pra marketing.
- Um produto só entra em `final/` com as duas aprovações humanas registradas.
